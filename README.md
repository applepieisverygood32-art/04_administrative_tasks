# 行政庶務 AI 協作模板庫

本 repository 用於整理行政庶務、臨時交辦事項、政策論述、長官簡報及各類行政文件相關之 AI 協作 Prompt 與模板。

本資料庫以：

「快速生成正式行政資料」

為核心目的。

---

# 主要用途

* 臨時簡報生成
* 長官交辦資料
* 政策論述整理
* 行政說明資料
* 臨時書面資料
* 對外回覆資料
* 委員意見回覆
* 跨單位協調資料
* 簡短技術說明

# 使用原則

1. 行政資料應保持正式與簡潔。
2. 涉及政策方向時應避免過度推論。
3. 對外資料須確認正式用語。
4. 長官簡報應優先考量可閱讀性與決策性。
